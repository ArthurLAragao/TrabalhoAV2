# Trabalho AV2 — Sistema de Gerenciamento de Biblioteca

Projeto desenvolvido em **Java** para a disciplina de **Programação Orientada a Objetos (POO)**.  
O sistema implementa o gerenciamento de **livros** e **membros de uma biblioteca**, aplicando conceitos fundamentais de orientação a objetos.

## 📌 Descrição

O projeto simula um sistema simples de biblioteca, permitindo organizar informações sobre livros e membros.  
A estrutura foi organizada dentro do pacote `src/POO`, separando as responsabilidades do sistema em classes.

## 🧠 Conceitos aplicados

- Programação Orientada a Objetos (POO)
- Classes e objetos
- Atributos e métodos
- Encapsulamento
- Construtores
- Relacionamento entre classes
- Organização de código em pacotes

## 🛠️ Tecnologias

- **Java**
- **IntelliJ IDEA**

## 🚀 Como executar

1. Clone o repositório:

```bash
git clone [https://github.com/ArthurLAragao/TrabalhoAV2.git](https://github.com/ArthurLAragao/TrabalhoAV2.git)
```

2. Abra o projeto no **IntelliJ IDEA**.

3. Localize a classe principal dentro de `src/POO`.

4. Execute o método `main` para iniciar o programa.

## 📚 Funcionalidades

- Cadastro e gerenciamento de livros
- Cadastro e gerenciamento de membros da biblioteca
- Organização dos dados utilizando classes Java
- Aplicação de princípios de orientação a objetos
